# Participant Guide (Film Photographer)

## 1. Overview
Participants are film photographers submitting their work. They are the primary users of the Web and Mobile Applications.

## 2. Main Functions (Based on Core Flow 3.1)

### 2.1. Login & Registration
- Login to the system.
- System checks participation eligibility.
- Register for a specific contest.

### 2.2. Profile Management
- Update personal profile.
- Manage equipment inventory (Film rolls, frame information, camera bodies, lenses) to streamline future submissions.

### 2.3. Submit Photographs
- Upload image files (Film scans).
- Mandatorily fill in technical metadata: Film brand, ISO, camera, lens, developing lab, scanning specifications, etc.
- **AI Interaction:** If a participant submits a duplicate photo or an AI-generated image, the system detects it and instantly returns an error or flags it for manual review by the Organizer.

### 2.4. Track Status
- Track submission status: Pending, Verified, Rejected.
- Receive final results and judge feedback after the contest ends.
