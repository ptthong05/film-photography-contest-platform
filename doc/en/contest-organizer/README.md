# Contest Organizer Guide

## 1. Overview
The Contest Organizer is the primary operator of a competition, responsible for everything from planning to result publication.

## 2. Main Functions (Based on Core Flow 3.3)

### 2.1. Create and Configure Contests
- Initialize new contests: Theme, categories, submission period, judging schedule, location, and awards.
- System saves configurations to the database.

### 2.2. Manage Registration & Assign Judges
- View the list of registered Participants.
- Update participant lists.
- Assign Judges to evaluate specific submissions or categories.

### 2.3. Verify Submissions
- Check submission validity (format, quality, deadline).
- Verify the completeness of analog metadata (Film stock, ISO, Lens, etc.).
- **AI Interaction:** The AI module automatically detects duplicate images or AI-generated content. The Organizer will conduct a manual review if the AI flags a submission.

### 2.4. Publish Results & Manage Awards
- Confirm results provided by judges.
- Publish provisional/official results.
- Organize online exhibitions.
- Move award-winning entries to the Digital Archive.
