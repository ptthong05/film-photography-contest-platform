# Administrator Guide

## 1. Overview
The Administrator is responsible for operating and monitoring the entire "AI-powered Film Photography Contest Management Platform".

## 2. Main Functions (Based on Core Flow 3.4)

### 2.1. Login and Authorization
- Access the system using Admin credentials.
- The system verifies access rights (RBAC).

### 2.2. System Management
- **User & Permissions Management:** Manage accounts for Organizers, Judges, and Participants. Can lock/unlock accounts.
- **System Configuration:** Configure basic system parameters.
- **Master Data Management:** Add/Edit master categories (e.g., adding new film stocks or vintage cameras to the selection list).
- **Activity Monitoring:** Monitor web traffic, system logs, and Cloud Storage health.
- **Maintain Contest Configurations (If assigned):** Assist Organizers in setting up complex contests.

## 3. Output
- All modifications are logged and securely saved to the core database.
