# Judge Guide

## 1. Overview
The Judge evaluates the technical and artistic merits of film photography submissions.

## 2. Main Functions (Based on Core Flow 3.2)

### 2.1. Receive Submissions
- Login to the system.
- Retrieve the list of assigned submissions.
- View high-resolution images along with all technical metadata (Film stock, ISO, Camera, Lens, Format, Scanning specs).

### 2.2. Evaluation & Scoring
- Score submissions based on configurable criteria (Composition, creativity, development technique, film grain, etc.).
- Provide comments.
- **AI Interaction:** The AI system may provide image analysis reports to assist (as suggestions).

### 2.3. Confirm Results
- Check if all judging rounds are completed.
- The system automatically aggregates scores and ranks submissions.
- Confirm final evaluation results and save them to the system.
