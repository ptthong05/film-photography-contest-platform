# AI-powered Film Photography Contest Management Platform
**Vietnamese:** Nền tảng tổ chức và quản lý cuộc thi nhiếp ảnh phim tích hợp trí tuệ nhân tạo

## Overview
A comprehensive web and mobile platform for managing film photography contests. It digitizes contest operations, integrates technical analog metadata (film stock, camera, ISO, lab, etc.), and establishes a centralized archive of film photography works.

## Key Features
- **Contest Planning & Configuration:** Create and manage contests with customizable categories and criteria.
- **Film Submission & Metadata:** Submit photos along with detailed film metadata (film brand, camera, lens, scan info).
- **AI-assisted Verification:** Detect duplicates, AI-generated images, and auto-categorize photos.
- **Judging & Evaluation:** Dedicated environment for judges to review and score submissions based on film-specific criteria.
- **Digital Archive:** Long-term preservation of award-winning photographs and historical contest records.

## System Roles
- **Administrator:** Manage users, settings, and master data.
- **Contest Organizer:** Create contests, verify submissions, assign judges, and publish results.
- **Judge:** Review and score submissions.
- **Participant:** Register, submit photos with metadata, and track status.

## Technology Stack
- **Frontend:** ReactJS / Next.js (Web), Flutter (Mobile)
- **Backend:** Java Spring Boot
- **Database:** PostgreSQL or MySQL
- **AI Integration:** Computer Vision, OpenAI API, Image Similarity Detection
- **Infrastructure:** Microsoft Azure / Firebase
